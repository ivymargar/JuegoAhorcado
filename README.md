🎮 Juego del Ahorcado

Juego inspirado en el clásico ahorcado desarrollado con HTML, CSS y JavaScript.

El jugador debe adivinar palabras utilizando pistas antes de que se complete el ahorcado.

Tecnologías utilizadas
- HTML
- CSS
- JavaScript

Funcionalidades
- Palabras aleatorias
- Sistema de pistas
- Sistema de puntuación
- Vidas limitadas
- Interfaz temática estilo videojuego retro
- Imágenes personalizadas

Contexto académico
Proyecto desarrollado para la página del ciclo DAM presentada durante la Feria Tecnológica FEVAL.
